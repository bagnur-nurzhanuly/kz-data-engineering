# Данные Казахстана глазами дата-инженера

Независимые инженерные разборы и исследования по открытым источникам: технологические кейсы казахстанских организаций и архитектура государственных данных — **DWH и ETL, интеграции, качество данных, Excel и ручные процессы, ошибки в отчётности**, а также Big Data и AI-инфраструктура.

Каждый материал строится на открытых источниках: годовых отчётах, законодательстве, интервью, отраслевых и международных исследованиях. Утверждения размечены:

| Метка | Что означает |
|---|---|
| **[ФАКТ]** | подтверждается первичным документом или официальным источником |
| **[ЗАЯВЛЕНИЕ КОМПАНИИ]** | показатель, опубликованный самой компанией, без независимой проверки методики |
| **[АНАЛИТИЧЕСКИЙ ВЫВОД]** | интерпретация нескольких подтверждённых фактов |
| **[ГИПОТЕЗА]** | возможная техническая проблема, которую нельзя подтвердить открытыми материалами |
| **[НЕИЗВЕСТНО]** | информация, которая не раскрывается в доступных источниках |
